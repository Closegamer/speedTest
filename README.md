# speedTest

Скрипт для измерения скорости интернет-соединения. Тестовое задание на вакансию Python Developer.

## Что делает

Скрипт принимает адрес (URL) файла для скачивания, последовательно выполняет N запросов (по умолчанию 10), дожидаясь ответа на каждый, и по итогам печатает:

- время и объём скачанных данных для каждого запроса;
- итоговый объём скачанных данных;
- среднее время одного запроса;
- среднюю скорость скачивания в MB/s.

## Установка

```bash
python -m venv venv
venv\Scripts\activate      # Windows
# source venv/bin/activate # Linux/macOS

pip install -r requirements.txt
```

Требуется Python 3.9+.

> Windows: если кириллица в консоли отображается некорректно, выполните `chcp 65001` перед запуском.

## Использование

```bash
python speedtest.py [URL] [-n COUNT] [-t TIMEOUT]
```

- `URL` — адрес файла для скачивания (например, тяжёлая картинка). Необязателен, по умолчанию используется фото Земли с Аполлона-17 (~6.5 MB) с серверов Wikimedia: `https://upload.wikimedia.org/wikipedia/commons/9/97/The_Earth_seen_from_Apollo_17.jpg`.
- `-n, --count` — количество запросов (по умолчанию 10).
- `-t, --timeout` — таймаут одного запроса в секундах (по умолчанию 30).

### Примеры

```bash
python speedtest.py
python speedtest.py https://proof.ovh.net/files/100Mb.dat -n 5
python speedtest.py https://upload.wikimedia.org/wikipedia/commons/9/97/The_Earth_seen_from_Apollo_17.jpg -n 10 -t 15
```

### Пример вывода

```
Тестируем скорость: https://upload.wikimedia.org/wikipedia/commons/9/97/The_Earth_seen_from_Apollo_17.jpg
Запросов: 10

  [1/10]     6.21 MB за   0.85 с ->   7.31 MB/s
  [2/10]     6.21 MB за   0.79 с ->   7.86 MB/s
  ...
  [10/10]    6.21 MB за   0.81 с ->   7.67 MB/s

Итог:
  Успешных запросов:      10/10
  Скачано данных:         62.10 MB
  Среднее время запроса:  0.81 с
  Средняя скорость:       7.67 MB/s
```

## Как это работает

Для каждого запроса скрипт замеряет время от начала запроса до получения полного тела ответа (`requests` со `stream=True`, чтение чанками по 64 КБ), считает объём скачанных байт. Итоговая средняя скорость = суммарный объём данных / суммарное время всех успешных запросов. Неудачные запросы (ошибки сети, таймауты) логируются в stderr и не учитываются в итоговых цифрах.
